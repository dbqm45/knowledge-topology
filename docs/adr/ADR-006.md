# ADR-006: Klasteryzacja hybrydowa

Status: przyjęta (2026-11-27)

## Decyzja

Leiden/Louvain na grafie wielosygnałowym wyznacza granice; HDBSCAN na embeddingach daje niezależny widok i confidence. Dokumenty niepasujące zostają nieprzypisane.

## Uzasadnienie

Samo podobieństwo embeddingów tworzy sztuczne obszary; sam graf linków pomija treść.

## Konsekwencje

LLM tylko nazywa klastry, nigdy nie wyznacza granic.
