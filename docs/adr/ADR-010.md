# ADR-010: Wersjonowane snapshoty

Status: przyjęta (2026-11-27)

## Decyzja

Każda topologia to snapshot z wersją algorytmu, modelu embeddingów i parametrami; stabilne klucze obszarów i lineage.

## Uzasadnienie

Porównywanie w czasie, odtwarzalność, audyt.

## Konsekwencje

Payload snapshotu w DB (object storage przy dużej skali).
