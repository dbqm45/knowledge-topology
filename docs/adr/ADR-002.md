# ADR-002: PostgreSQL jako źródło prawdy

Status: przyjęta (2026-11-27)

## Decyzja

Dokumenty, wersje, ACL, encje, relacje, snapshoty, metryki, issues i audyt w PostgreSQL (SQLite w trybie dev/test). Schemat przez Alembic.

## Uzasadnienie

Transakcyjność, JSONB, jedno źródło prawdy dla ACL.

## Konsekwencje

Indeks wektorowy jest pochodną i może być odbudowany z bazy + źródeł.
