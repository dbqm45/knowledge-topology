# ADR-003: Qdrant jako indeks wektorowy

Status: przyjęta (2026-11-27)

## Decyzja

Wektory chunków w Qdrant (lokalny plik numpy w dev). Payload: tenant, dokument, ACL jako pre-filtr.

## Uzasadnienie

Filtrowanie po payloadzie, dojrzałość, łatwe uruchomienie lokalne.

## Konsekwencje

Payload ACL nie jest zabezpieczeniem — autorytatywny filtr jest w `AccessService`.
