# ADR-011: MCP nad wspólnymi usługami

Status: przyjęta (2026-11-27)

## Decyzja

REST i MCP wywołują tę samą fasadę `KnowledgeService`; MCP nie ma własnej logiki wyszukiwania ani autoryzacji; tożsamość z klucza połączenia.

## Uzasadnienie

Spójność odpowiedzi i bezpieczeństwa między ludźmi i agentami.

## Konsekwencje

Kompaktowe odpowiedzi MCP (bez wcięć i nulli) dla oszczędności tokenów.
