# ADR-007: Osobny Geometry Engine

Status: przyjęta (2026-11-27)

## Decyzja

Kształt jest deterministyczną funkcją metryk i struktury (r(θ), wyspy, nici), z listą wyjaśnień.

## Uzasadnienie

Metryki są źródłem prawdy; geometria ich reprezentacją. Zapobiega „ładnym, ale nieprawdziwym” mapom.

## Konsekwencje

Zmiana formuły geometrii nie zmienia metryk; wersja algorytmu w snapshocie.
