# ADR-001: Modularny monolit + workery

Status: przyjęta (2026-11-27)

## Decyzja

Jeden pakiet `kt` z wyraźnymi modułami (connectors, ingestion, semantic, topology, intelligence, retrieval, access, api, mcp) i osobnymi procesami (api, worker, mcp).

## Uzasadnienie

Mikroserwisy od początku zwiększyłyby koszt wdrożenia i zmian modelu danych. Granice modułów pozwalają wydzielić usługi później (np. embeddingi, layout).

## Konsekwencje

Skalowanie kosztownych zadań przez osobne workery; brak rozproszonych transakcji.
