# ADR-012: Wielowymiarowa jakość bez ukrywania niepewności

Status: przyjęta (2026-11-27)

## Decyzja

Osiem niezależnych metryk z confidence, sample size i flagą measured/estimated; composite health tylko pomocniczo.

## Uzasadnienie

Jeden wskaźnik ukrywa problemy (np. spójna, ale nieaktualna dokumentacja).

## Konsekwencje

Coverage bez modelu oczekiwanej wiedzy jest oznaczone jako estimated.
