# ADR-005: Kanoniczny model dokumentu

Status: przyjęta (2026-11-27)

## Decyzja

Każdy connector zwraca `NormalizedDocument` (sekcje z typem i ścieżką nagłówków, linki, efektywne ACL, wersja, metadane surowe).

## Uzasadnienie

Silnik topologii nie zna Confluence; nowe źródła = nowy connector.

## Konsekwencje

Pola specyficzne dla źródła trafiają do `raw_metadata`.
