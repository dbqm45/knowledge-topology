# ADR-004: Graf w PostgreSQL na start

Status: przyjęta (2026-11-27)

## Decyzja

Tabela `relations` z typami końców (document/entity/domain), wagą, confidence, provenance i dowodami. Analizy grafowe w NetworkX w pamięci podczas budowy snapshotu.

## Uzasadnienie

Wystarcza do sąsiedztwa i hierarchii; unikamy drugiego źródła prawdy.

## Konsekwencje

Neo4j/AGE gdy pojawią się wieloetapowe traversale online.
